# 📚 Sistema Livraria Fácil - Wireframes & Frontend

Projeto de interface e fluxo de navegação desenvolvido para o sistema de gestão de livrarias **Livraria Fácil**. O projeto contempla o cadastro e consulta de acervo, gestão de clientes, realização de vendas e histórico de transações.

---

## 🖥️ Telas do Sistema

### 1. Página Inicial (`index.html`)
Painel principal de navegação com acesso rápido aos módulos do sistema.
![Página Inicial](images/index.png)

### 2. Gestão de Livros (`livros.html`)
Formulário de cadastro de títulos (ISBN, Autor, Categoria, Custos, Preço e Estoque) e listagem do acervo.
![Gestão de Livros](images/livros.png)

### 3. Gestão de Clientes (`clientes.html`)
Módulo de cadastro e consulta de clientes cadastrados (Nome, CPF, E-mail e Telefone).
![Gestão de Clientes](images/clientes.png)

### 4. Ponto de Venda (`venda.html`)
Fluxo de seleção de cliente, adição de itens ao carrinho e finalização do pedido.
![Realizar Venda](images/venda.png)

### 5. Histórico de Vendas (`historico.html`)
Consulta detalhada de transações realizadas com identificação do cliente, data, itens e valor total.
![Histórico de Vendas](images/historico.png)

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação das telas e formulários.
- **CSS3**: Estilização dos componentes e layouts responsivos.
- **Git / GitHub**: Controle de versão e hospedagem do repositório.
